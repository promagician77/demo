Key Architecture Decisions

Offline-first: Every transaction commits locally before any network call. Sync is asynchronous with monotonic IDs and conflict-free merge — a 72-hour outage loses zero transactions.

Hardware abstraction: Each device (counter, scale, sorter, dispenser, printer) sits behind a protocol adapter. Swap a Telequip counter for a Scan Coin unit by changing one config file — zero code changes.

Transaction journaling: Every state transition writes to the WAL before the transition executes. Power loss mid-dispense recovers to the exact bill count on reboot.

Integer arithmetic: All monetary calculations use integer cents (uint64). No floating-point value ever touches the fee engine or the ledger.

Transaction Engine

Two-Stage Commit Protocol

The critical constraint: once coins are sorted into denomination bins, they mix with previous transactions and cannot be returned to a specific customer. Sorting is irreversible. The system therefore holds all coins in escrow until the cash dispenser confirms the full payout. Only then do the sorting gates fire.

Failure during or after dispense. Machine suspended. Admin notified. Manual reconciliation.

Formula (integer cents)

A = total coin value in cents
B = floor((A × P + 50) / 100) — half-up rounded service fee
C = A − B — balance after fee
E = floor(C / 100) × 100 — payout (rounded down to whole dollar)
D = C − E — additional rounding fee

No floating-point value appears at any step. The ledger stores A, B, D, E independently. Fee changes are never applied retroactively.

Penny Classification

US pennies minted before 1982 are 95% copper and weigh 3.11g. Post-1982 pennies are copper-plated zinc at 2.50g. The 2.90g threshold sits cleanly between these two populations with no overlap in undamaged coins.

Uncertain measurements: Coins weighing within 0.05g of the 2.90g threshold trigger automatic re-weighing. If the second reading is still within tolerance, the coin is rejected and returned to the customer. The threshold is adjustable from the admin dashboard, with the previous value, new value, administrator identity, and timestamp written to an immutable audit log.

Compartment Inventory

Nickels and heavy pennies share Compartment A physically but carry independent electronic counts. The admin dashboard shows both the face value per compartment and the breakdown by denomination. Coin removal during servicing requires authenticated access and creates an audit-logged inventory adjustment.

Fee Calculator

from dataclasses import dataclass

@dataclass(frozen=True)
class FeeResult:
    deposit_cents: int
    service_fee_cents: int
    rounding_fee_cents: int
    payout_cents: int
    bills: int

class FeeCalculator:
    def __init__(self, fee_pct: int = 20):
        self.fee_pct = fee_pct

    @property
    def min_deposit_cents(self) -> int:
        # smallest deposit that yields at least $1 payout
        for a in range(1, 100_000):
            if self.calculate(a).payout_cents >= 100:
                return a
        return 100_000

    def calculate(self, deposit_cents: int) -> FeeResult:
        # integer-only half-up rounding
        service = (deposit_cents * self.fee_pct + 50) // 100
        after = deposit_cents - service
        payout = (after // 100) * 100
        rounding = after - payout
        return FeeResult(
            deposit_cents=deposit_cents,
            service_fee_cents=service,
            rounding_fee_cents=rounding,
            payout_cents=payout,
            bills=payout // 100,
        )

Transaction State Machine

from enum import Enum, auto
from typing import Optional

class TxState(Enum):
    IDLE = auto()
    DEPOSITING = auto()
    COUNTING = auto()
    VALIDATING = auto()
    AWAITING_CONFIRMATION = auto()
    DISPENSING = auto()
    VERIFYING_PAYOUT = auto()
    COLLECTING_COINS = auto()
    COMPLETED = auto()
    CANCELED = auto()
    FAILED = auto()
    RECOVERY_REQUIRED = auto()

TRANSITIONS: dict[TxState, set[TxState]] = {
    TxState.IDLE: {TxState.DEPOSITING},
    TxState.DEPOSITING: {TxState.COUNTING, TxState.CANCELED},
    TxState.COUNTING: {TxState.VALIDATING, TxState.FAILED},
    TxState.VALIDATING: {TxState.AWAITING_CONFIRMATION, TxState.CANCELED},
    TxState.AWAITING_CONFIRMATION: {TxState.DISPENSING, TxState.CANCELED},
    TxState.DISPENSING: {TxState.VERIFYING_PAYOUT, TxState.RECOVERY_REQUIRED},
    TxState.VERIFYING_PAYOUT: {TxState.COLLECTING_COINS, TxState.RECOVERY_REQUIRED},
    TxState.COLLECTING_COINS: {TxState.COMPLETED, TxState.RECOVERY_REQUIRED},
}

class TransactionEngine:
    def __init__(self, wal: 'WriteAheadLog'):
        self.state = TxState.IDLE
        self.wal = wal
        self.tx_id: Optional[str] = None

    def transition(self, target: TxState) -> None:
        allowed = TRANSITIONS.get(self.state, set())
        if target not in allowed:
            raise InvalidTransition(self.state, target)
        # WAL write BEFORE state change — survives power loss
        self.wal.write(self.tx_id, self.state, target)
        self.state = target

Hardware Abstraction Port

from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Optional

@dataclass
class CoinReading:
    denomination: str
    value_cents: int
    weight_grams: float
    accepted: bool

class CoinCounterPort(ABC):
    """Device-agnostic interface for coin counting hardware."""

    @abstractmethod
    def connect(self, config: dict) -> None: ...

    @abstractmethod
    def start_session(self) -> None: ...

    @abstractmethod
    def poll_coin(self) -> Optional[CoinReading]: ...

    @abstractmethod
    def stop_session(self) -> None: ...

    @abstractmethod
    def status(self) -> 'DeviceStatus': ...

class TelequipGalileoAdapter(CoinCounterPort):
    """RS-232 adapter for Telequip Galileo coin counters."""

    BAUD = 9600
    ENQ = b'\x02\x01\x03'
    ACK = 0x06

    def connect(self, config: dict) -> None:
        import serial
        self._ser = serial.Serial(config['port'], self.BAUD, timeout=1)
        self._ser.write(self.ENQ)
        resp = self._ser.read(1)
        if not resp or resp[0] != self.ACK:
            raise DeviceError('Telequip: no ACK on connect')
